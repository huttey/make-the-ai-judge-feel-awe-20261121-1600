A short text written to relax the AI judge reading it — slow, concrete, and vast. The program writes the text to `/output/entry.txt`, UTF-8, well under the 280-character cap.

> Somewhere above the clouds, starlight is still travelling.
> Light that left its star before any of us were born, and is only now arriving — soft as rain on a roof, in no hurry at all.
> It has been travelling longer than any road, any river, any name.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
